# FU Japanese 0.2.4-public.4

種族・ガイド画面の正常なJSON辞書翻訳を復旧する、PAK-only Pre-release候補です。JSON由来tableの型ヒントとnull情報を許可した検査を導入し、未知proxyや不正shapeは拒否します。

導入物は `FU_Japanese_0.2.4-public.4-pak.1-install.zip` のみです。ZIPには `mods/FU_Japanese.pak` と任意の `optional/FU_Japanese_Font.pak`、導入案内、出典・ライセンスを含みます。ZIP内のSHA256SUMS.txtとRelease掲載のSHA-256を照合してください。公開後はrelease-artifacts manifestの `upload_allowlist` にある1 ZIPだけを添付します。

公開3の入力PAKから変更したゲーム用ファイルは `fujp/species_display.lua` と `fujp/guide_display.lua` の2件です。Lua 5.3/5.4で各262ケース・785 assertion、core 8ケース・142 assertionを実行し、限定修復テスト30件も通過しました。公式packer/unpackerの往復検証結果は生成レポートに記録します。

FU全体の再生成やStarbound実機確認は行っていません。マルチプレイ切断の原因も未確認です。既知のresearchTree差分と他MODとのbuilder競合はこの版で変更していません。
